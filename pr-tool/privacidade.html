Última atualização: 28 de julho de 2026

Política de privacidade

O Brasil Tools prioriza ferramentas locais no navegador e coleta mínima para funcionamento e melhoria do site.

Dados digitados nas ferramentas

Textos, imagens, CPFs, CNPJs, chaves Pix, listas de sorteio e valores digitados nas ferramentas são processados no navegador sempre que a página indica uso local. Esses dados não precisam ser enviados para um servidor do Brasil Tools para a tarefa funcionar.

Armazenamento local

Algumas ferramentas podem usar LocalStorage para manter preferências ou dados temporários no próprio navegador, como o Racha Pix. Você pode apagar esses dados limpando o armazenamento do site no navegador.

Analytics

O site usa Vercel Web Analytics para entender visitas, páginas acessadas e desempenho geral. Esse recurso ajuda a melhorar páginas populares e identificar erros de navegação.

Anúncios

O site pode exibir anúncios, incluindo Google AdSense. Serviços de anúncio podem usar cookies ou identificadores conforme suas próprias políticas para medir desempenho e personalizar anúncios quando aplicável.

Contato

Para dúvidas sobre privacidade, use a página de contato. Não envie senhas, documentos completos, chaves Pix ou dados sensíveis em mensagens de contato.
