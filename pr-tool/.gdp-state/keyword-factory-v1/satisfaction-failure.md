# S/F Matrix

## 满意标准（S）

- S1：负责人打开产物后，能立刻看到候选工具、市场覆盖、关键词覆盖和当前数据可信度。
- S2：可以筛选出“高商业价值、较低竞争、开发成本可控”的下一批 MVP 机会。
- S3：每个真实指标都能定位到来源、采集时间、地域与语言口径。
- S4：数据库可以持续导入新指标并重新计算优先级，不需要手工重建整张表。
- S5：首批本地关键词不是简单逐字翻译，而是明确标记本地化与母语验证状态。
- S6：项目可跨多轮继续，不依赖聊天历史恢复上下文。

## 失败模式（F）

- F1：为了凑 20,000 条而填入虚假搜索量、CPC 或难度。
- F2：表格只有关键词文本，没有来源、口径、状态和更新时间。
- F3：把翻译产物当成当地用户真实搜索词，直接生成大量低质量页面。
- F4：评分公式不可解释，优先级只是主观星级换皮。
- F5：一次性表格无法增量导入、去重或重算。
- F6：数据库建设拖太久，首周没有可用于验证的 MVP 子集。

## Value Targets（高价值目标）

| 编号 | 来源 | 高价值原因 | 优先级 |
|---|---|---|---|
| V1 | S3,F1,F2 | 可信度决定数据库是否真能成为资产 | P0 |
| V2 | S2,F4 | 决定实际产品顺序和资源投入 | P0 |
| V3 | S4,F5 | 决定能否持续迭代 6–12 个月 | P0 |
| V4 | S5,F3 | 决定多语言 SEO 是否会变成批量低质量页面 | P0 |
| V5 | S1,S6,F6 | 保证首周可见成果与长期交接 | P1 |
