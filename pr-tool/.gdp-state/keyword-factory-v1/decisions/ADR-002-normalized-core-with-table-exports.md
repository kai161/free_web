# ADR-002 以 SQLite 为规范化核心，CSV/XLSX 为协作出口

## 状态

accepted — 2026-07-17

## 背景

项目既需要外键、去重、历史快照和增量导入，又需要负责人能直接筛选和浏览数据。

## 决策

- SQLite 是 v1 的规范化交付核心。
- CSV 是供应商导入、批量编辑和系统交换格式。
- Excel 是决策浏览与汇报格式，不作为唯一事实源。
- 所有可再生产物由脚本生成，避免手工表格漂移。

## 后果

- 单机阶段部署简单，后续可以迁移到 PostgreSQL。
- 工作簿内手工修改不会自动回写 SQLite；需要通过受控导入流程。
- 大规模并发编辑不是 v1 目标。
