# Reality Map

## 仓库当前事实

- 当前目录是一个葡萄牙语/巴西市场的静态工具与内容站。
- 已有页面包含图片、PIX、WhatsApp、短语和字符计数等方向。
- `contador-caracteres.html` 与 `link-whatsapp.html` 当前未跟踪，属于用户现有工作。
- 仓库没有现成的关键词数据库或指标导入流程。

## 用户提供的战略事实

- 用户希望把项目视为 6–12 个月创业项目。
- 核心定位是 Keyword Factory：关键词 → SEO 页面 → 工具 → 内容资产。
- 目标资产是 200 工具、10 个首批国家、约 20,000 关键词及商业/竞争/优先级数据。
- 原始来源：`https://chatgpt.com/share/6a59f54f-b9a0-83ec-98b9-79999c283241`，页面标题“TrustMRR 平台评估”。

## 外部资料当前事实

- Google Ads `KeywordPlanIdeaService` 支持按关键词/URL 种子、地域和语言生成关键词与历史指标。
- Google Trends 支持跨语言、地区比较，但指标是相对热度，不应当作绝对搜索量。
- Ahrefs 的多语言 SEO 方法强调地区与语言组合、当地搜索意图，而不是只翻译页面。

## 尚未取得的事实

- 20,000 个关键词的真实月搜索量、CPC、Google Ads 竞争和 SEO 难度。
- 每个关键词的当地 SERP 竞争者、结果类型和首页强度。
- 机器/编辑生成本地关键词的母语与 SERP 验证结果。
