# Assumptions

## A001 首批 10 个市场沿用用户建议

- 状态：pending
- 验证方式：用真实搜索量、CPC、竞争、互联网商业价值和本地 SERP 结果重排。
- 被推翻后的影响：调整市场 wave，不影响数据模型。

## A002 首批 MVP 以低后端依赖工具优先

- 状态：pending
- 验证方式：对照真实关键词机会与当前静态站点能力。
- 被推翻后的影响：提高 AI/服务端工具权重并调整部署架构。

## A003 每个工具市场先生成约 10 个意图变体足以用于第一轮发现

- 状态：pending
- 验证方式：Google Ads Keyword Ideas、Google Trends 和 SERP 相关搜索补全后比较召回率。
- 被推翻后的影响：增加本地化 pattern 或改为数据源返回的关键词为主。

## A004 用户提供的共享对话代表当前战略方向

- 状态：verified
- 验证方式：用户明确提供来源，并在当前对话粘贴核心方案。
- 被推翻后的影响：更新目标契约。
