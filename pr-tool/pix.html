Calculadora Pix para dividir conta

Use o Racha Pix para dividir churrasco, viagem, almoço, mercado ou rolê. A ferramenta calcula o total, a parte de cada pessoa e os acertos mínimos.

Como dividir uma conta com Pix?

Adicione os participantes, informe quem pagou cada despesa e a ferramenta calcula os menores acertos entre as pessoas.

Os dados do grupo ficam online?

Não. Os nomes, despesas e chaves Pix ficam salvos apenas no LocalStorage do navegador.
