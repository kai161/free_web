Jogo da Velha grátis para celular

O Jogo da Velha é um clássico para preencher uma pausa rápida no ônibus, na fila ou no intervalo. Esta versão roda inteira no navegador, com tabuleiro grande para toque e placar local.

Precisa instalar aplicativo?

Não. A página é leve, abre direto no navegador e não depende de login, API externa ou download.
