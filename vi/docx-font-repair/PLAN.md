# 越南语 DOCX 字体编码修复第一版

目标：在 free_web 现有 vi 模块内提供本地、可审阅、可取消的保守修复。
架构：经典本地 JS + 原生 DOMParser/DecompressionStream；ZIP 原始压缩资源透传；只修改选择的词片段并局部覆盖字体。
技术栈：原生浏览器，无第三方运行依赖，无端口，无广告/统计。

实现阶段用户已批准原方案并指定此仓库，当时不创建 worktree、不提交、不推送。2026-10-10 用户另行明确授权提交、推送并验证已有项目的自动部署。

1. 先保存人工编写、来自独立公开文本的已知答案。覆盖 TCVN3、H 大写、继承样式、跨 run、softHyphen、表格和 Unicode 控制；VNI 与未知词须原样标记。
2. 实现有界 ZIP 读写，拒绝加密、签名、宏、复杂修订和未支持的 XML；未修改条目保留原始压缩数据。
3. 实现按字体片段和继承解析，74 个已核对字符映射 + 越南语音节结构保护。Unicode 可能正确时保留，只转换明确片段，不用 GPL UniKey 或未经验证的通用映射。
4. 双语隔离页面、内置示例、逐项取消、另存与重复操作。每次另存从原始 XML 重建。
5. Mac 浏览器直接打开验收，并用 Python ZIP/XML 检查导出及资源一致性；记录范围与限制。
