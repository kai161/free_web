Image to Base64：前端性能优化利器

Base64 编码是一种将二进制图片数据转换为文本字符串的方法。在前端开发中，将小图标（Icons）转换为 Base64 DataURI 并直接嵌入 HTML 或 CSS 文件中，可以有效地减少浏览器的 HTTP 请求次数，从而显著提升页面的加载速度和性能评分。

适用场景与局限性

Base64 编码后的字符串通常会比原始二进制文件体积增大约 33%。因此，它最适合用于体积小于 10KB 的小图、矢量图标或装饰性元素。对于大尺寸照片，建议依然采用传统的 WebP 或 JPG 引用方式，以保持 HTML 文件的轻量化。
